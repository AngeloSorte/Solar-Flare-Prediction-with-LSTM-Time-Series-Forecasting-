# Solar Flare Prediction with LSTM

This project explores solar flare prediction using a Long Short-Term Memory (LSTM) neural network for time series forecasting.

The model is trained on simulated X-ray flux data inspired by GOES satellite observations, designed to replicate the temporal behavior of solar activity and flare-related patterns.

## Project Features
- Time series preprocessing and normalization
- Sequence generation for LSTM models
- LSTM-based regression for short-term forecasting
- Visualization of actual vs predicted solar X-ray flux
- Fully compatible with Google Colab

## Motivation
Solar flares can significantly impact satellite operations, GPS systems, and power grids. Machine learning techniques like LSTMs are well suited to modeling temporal dependencies in space weather data.

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Scikit-learn
- Matplotlib

## Notes
The current version uses simulated data for stability and reproducibility. The pipeline is designed to be easily extended to real NASA/NOAA GOES datasets.
